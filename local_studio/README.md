# GTA 6 Clipping Studio — Windows local edition

## Start

1. Install Python 3.11+ and FFmpeg (including ffprobe) and add both to PATH.
2. Install eSpeak NG for English voice commentary (add `espeak-ng.exe` to PATH).
3. Download the GitHub repository as a ZIP and extract it.
4. Double-click `local_studio/start_windows.bat`.
5. In the browser click **Find GTA 6 videos**, optionally **Fetch comment counts and rank**, select a video, confirm rights, then click **Download source and create MP4 clips**.
6. Download the resulting ZIP. MP4 files are also in `local_output/clips/`.

YouTube access and metadata are not guaranteed. No Google API key required. Video downloads may be blocked. Narration is generic rather than scene-aware, and editing does not guarantee copyright clearance. Only process footage you are authorized to download and reuse.
