# GTA 6 Clipping Studio v1.8.5 — Automatic Cinematic Colour

Based on v1.8.4. All prior release branches are preserved.

## New
Section 3 now applies **Natural cinematic** colour grading by default to each successfully downloaded recommended clip. Other options are Vibrant GTA, Warm sunset, Cool neon and Original. The edited clips are saved separately, and the batch ZIP contains the graded versions when successful. The source MP4s remain intact.

Optional region blur from v1.8.4 remains available for footage you own or have permission to alter. It is not automatically enabled. Colour grading does not remove watermarks or replace attribution.

## Windows
Extract the v1.8.5 ZIP to a new folder, launch `local_studio/start_windows.bat`, search and select the video, analyze comments, select a Video look, confirm usage rights, and click Download all recommended 30-second clips.

This change has been committed but has not been verified on the user's Windows installation.
